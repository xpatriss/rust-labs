# Lab 3

Drzewo wyrażeń symbolicznych: stałe (liczbowe i nazwane), zmienne `X`, `Y`, `Z`, dodawanie, mnożenie, negacja, odwrotność i funkcja jednej zmiennej.

Wyrażenie da się wypisać, podstawić wartość pod stałą nazwaną, zwinąć podwójną negację i podwójną odwrotność oraz policzyć pochodną symboliczną.

Ćwiczone rzeczy: `enum`, `Box`, rekurencja po drzewie, testy jednostkowe.

```
cargo test
cargo run
```
