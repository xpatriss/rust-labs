# Lab 3

A symbolic expression tree: numeric and named constants, variables `X`, `Y`, and `Z`, addition, multiplication, negation, inverse, and a function of one argument.

An expression can be printed, have a value substituted for a named constant, have a double negation or a double inverse folded away, and be differentiated symbolically.

Covers `enum`, `Box`, recursion over a tree, and unit tests.
