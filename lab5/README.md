# Lab 5

Mały język zbudowany na dwóch cechach: `Expr` (wyrażenie zwraca `u64`) i `Stmt` (instrukcja nic nie zwraca).

Są wypisanie, pusta instrukcja, sekwencja dwóch instrukcji (z uproszczeniami, gdy któraś jest pusta), warunek, powtórzenie z liczbą iteracji w typie, odczyt stałej z kontekstu, odczyt zmiennej z zewnątrz, zapis do zmiennej i wariant, który na czas obliczenia podmienia wartość w kontekście.

Ćwiczone rzeczy: traity, generyki, const generics, czasy życia, testy zagnieżdżonych programów.

```
cargo test
cargo run
```
