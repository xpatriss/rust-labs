# Lab 1

The program reads numbers from the console. It adds a random value from 0 to 5 to each one, computes the next ten powers, and checks whether the Collatz conjecture holds for them within a limited number of steps. The result is written to `xyz.txt`. The loop ends on zero or on invalid input.

It finishes with a short game: the program fills a 5×5 matrix at random and checks whether the number you enter appears in it.

Covers loops, `match`, arrays, writing a file, and the `rand` crate.

```
cargo run
```
