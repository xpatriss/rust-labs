# Lab 1

Program wczytuje liczby z konsoli. Do każdej dodaje losową wartość z zakresu 0–5, liczy dziesięć kolejnych potęg i sprawdza, czy dla nich zachodzi hipoteza Collatza (w ograniczonej liczbie kroków). Wynik trafia do pliku `xyz.txt`. Pętla kończy się zerem albo błędnym wejściem.

Na końcu jest krótka gra: program losuje macierz 5×5 i sprawdza, czy podana liczba w niej występuje.

Ćwiczone rzeczy: pętle, `match`, tablice, zapis do pliku, crate `rand`.

```
cargo run
```
